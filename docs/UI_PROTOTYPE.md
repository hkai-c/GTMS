## 1. 设计总则

### 1.1 设计原则

- 简洁实用，面向制造业用户
- 左侧导航 + 右侧内容区经典布局
- 状态用颜色区分，一目了然
- 表单实时校验，错误即时提示
- 关键操作二次确认

### 1.2 窗口规格

| 属性 | 桌面端 | 小程序 |
|------|------|------|
| 最小分辨率 | 1280 × 720 | 375 × 667 (iPhone 6/7/8) |
| 推荐分辨率 | 1440 × 900 | 375 × 812 (iPhone X) |
| 字体 | Microsoft YaHei 9pt | 系统默认 |
| 主题色 | #1890FF (蓝色) | #1890FF |

### 1.3 通用组件库

| 组件 | 说明 |
|------|------|
| StatusBadge | 状态标签，6 种颜色 |
| SearchBar | 搜索栏（关键词 + 状态下拉 + 日期范围） |
| FileUploader | 拖拽/点击上传，支持预览 |
| ImageViewer | 图片预览弹窗，支持缩放旋转 |
| ConfirmDialog | 二次确认对话框 |
| Pagination | 分页组件（每页 20 条） |

### 4.2 统计卡片

| 卡片 | 内容 | 数据来源 |
|------|------|------|
| 今日新任务 | 今日创建的任务数 | `COUNT WHERE created_at = today` |
| 待收件 | 当前 pending_receipt 状态数 | `COUNT WHERE status='pending_receipt'` |
| 试磨中 | 当前 grinding 状态数 | `COUNT WHERE status='grinding'` |
| 本月完成 | 本月完成数 + 完成率 | `COUNT WHERE status='completed' AND month=current` |

### 4.3 消息面板

- 红色圆点 = 未读
- 点击消息 → 标记已读 + 跳转到对应任务详情
- "全部已读"按钮清空未读标记
